# Miss Minutes 3D asset

Unofficial original fan-made recreation of the animated clock character. This is a real glTF 2.0 binary scene, not a rendered image or 2D sprite. Geometry is generated from the checked-in source script.

## Files

- \`assets/models/miss-minutes.glb\` — 681 KB GLB with 120 nodes, 24 meshes, 15 PBR materials and 17 animation clips.
- \`assets/models/miss-minutes.manifest.json\` — scene inventory and animation contract.
- \`tools/build-model.mjs\` — dependency-free Node.js generator.
- \`tools/validate-model.mjs\` — structural and animation validator.
- \`preview.html\` — interactive orbit preview with all animation clips.
- \`app/src/main/assets/models/miss-minutes.glb\` — Android asset copy, regenerated by CI from the same source.

## Rig and known limitations

The current asset uses a hierarchical transform rig with independently controlled body, shoulders, elbows, wrists, hands, hips, knees, ankles, eyes, brows and mouth variants. This is lightweight for mobile real-time rendering.

The current GLB does not contain a skinned mesh, morph targets or texture images. Facial expressions use animated transform controls and alternate mouth geometry. It is a genuine animated 3D scene, but it is not a film-production character rig. No extracted Marvel/Disney production assets are included.

## Build and validate

\`\`\`bash
node tools/build-model.mjs
node tools/validate-model.mjs
\`\`\`

The GLB can be imported into Three.js, Godot, Unity, Blender and other glTF-compatible tools.
